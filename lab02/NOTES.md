Рабочая папка - папка на устройстве, в которой лежат файлы проекта
Индекс - это область, в которой хранятся файлы до коммита
коммит - снимок всех файлов репозитория в конкретный момент времени
git - это программа на компьютере, которая управляет историей измений кода локально
github - это сервис облачного хранения репозиториев на базе git

git diff показывает разницу директорием и индексом, git diff --staged показывает разницу между индексом и последним коммитом

Использованные команды:
git status - показывает текущий статус репозитория.
gut diff - показывает разницу директорием и индексом
git diff --staged показывает разницу между индексом и последним коммитом

Ветка - это ссылка на конкретный коммит в истории проекта
При добавлении коммита в ветку ее указатель перемещается на новый коммит
При слиянии веток ветки объединяются в одну ветку с помощью коммита слияния
