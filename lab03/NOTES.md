git diff показывает изменения между вариантами состояний кода. 
git show отображает информацию о конкретнном объекте и его изменениях
git log выводит историю коммитов списком.
git log -s"def" показывает коммиты, в которых количество упоминаний "def" изменилось.
git blame напротив каждой строки файла отображает хэш коммита, дату и время последнего изменения строки, а также автора изменения

git restore берет версию файла из индекса и заменяет ею незакоммиченную версию в директории.
git restore --source... заставляет игнорировать индекс и взять версию файла напрямую из конкретного коммита ии заменяет ею незакоммиченные изменения файла (и в директориии и в индексе)

revert не стирает коммит, а создает новый, не отменяя изменения. git reset -- hard перематывает указатель ветки на выбранный коммит. Все коммиты, которые были сделаны после него, исчезают.
