git diff показывает изменения между вариантами состояний кода. 
git show отображает информацию о конкретнном объекте и его изменениях
git log выводит историю коммитов списком.
git log -s"def" показывает коммиты, в которых количество упоминаний "def" изменилось.
git blame напротив каждой строки файла отображает хэш коммита, дату и время последнего изменения строки, а также автора изменения
